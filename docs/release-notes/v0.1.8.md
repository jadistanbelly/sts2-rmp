# Remove Multiplayer Player Limit v0.1.8 Notes

## Summary

- Recovers the Harmony-free Nexus 0.1.7 implementation into source control.
- Fixes loaded-run host lobbies that are created with Steam's vanilla 4-player member limit.
- Adds focused tests for loaded-run Steam lobby capacity synchronization.
- Adds release packaging scripts and Nexus upload workflow.

## Root Cause

Loaded-run and save-slot continuation flows can create a Steam lobby through a path that starts with the vanilla member limit of 4. The existing RMP start-run path repaired lobby capacity, but the loaded-run lobby path only logged state and did not update the Steam lobby member limit.

## Fix

When a loaded-run lobby is active on the host, RMP now:

- Binds the RMP protocol to the host network service.
- Reads the current Steam lobby member limit.
- Updates the Steam lobby member limit to 16 when needed.
- Logs before/after capacity values for debugging.

## Build Note

STS2 rejects PCK files built with local Godot 4.6.3. The local test package reused the existing compatible Nexus PCK while rebuilding the DLL.

Package artifact path:

```text
build/sts2-RMP-0.1.8.zip
```

Calculate the local artifact hash after packaging with:

```bash
sha256sum build/sts2-RMP-0.1.8.zip
```
